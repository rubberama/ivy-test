# 나에게 맞는 아이비리그는? — 성향 매칭 테스트

18개 질문에 답하면 아이비리그 8개교 중 나와 결이 맞는 학교 세 곳을 매칭 적합도와 함께 알려주는 한 페이지 웹 테스트입니다. 한국에서 유행하는 "유형테스트" 포맷을 따랐고, 타겟은 17~21세입니다.

> **이건 성향 매칭이지 합격 예측이 아닙니다.** 성적·시험 점수·스펙을 묻는 질문은 하나도 없고, 합격 가능성을 추정하지도 않습니다.

## 실행

빌드 과정이 없습니다. 둘 중 아무거나 하면 됩니다.

```bash
# 1. 그냥 파일을 더블클릭 (file:// 로 열림)
open index.html

# 2. 로컬 서버 (공유 링크 기능까지 쓰려면 이쪽)
python3 -m http.server 8000
```

`file://` 로 열어도 전부 동작합니다. 단 결과 **링크 공유**만 비활성화됩니다 (`file:///Users/...` 주소는 남에게 보내도 안 열리니까요). `js/share.js` 의 `SITE_URL` 에 배포 주소를 넣어두면 그 경우에도 켜집니다.

## 배포

정적 파일뿐이라 설정 없이 그대로 올라갑니다.

- **GitHub Pages** — 저장소 Settings → Pages → 브랜치 루트 선택
- **Vercel / Netlify** — 저장소 연결 후 빌드 명령 비움, 퍼블리시 디렉터리 `/`

## 구조

```
index.html                     인트로 / 질문 / 결과 세 화면을 JS 로 토글
styles.css                     디자인 토큰 + 전체 스타일
js/data/axes.js                성향 축 7개 정의
js/data/schools.js             8개교 프로필 (벡터 + 해설)
js/data/questions.js           18개 질문 + 축 가중치
js/scoring.js                  정규화 · 코사인 유사도 · 퍼센티지
js/share.js                    답변 <-> URL 해시 인코딩
js/resultImage.js              canvas 결과 이미지 (1080x1350)
js/app.js                      상태 머신 · 렌더링 · 이벤트
scripts/check-reachability.js  매칭 엔진 검증 (node 로 실행)
```

`<script type="module">` 을 쓰지 않고 일반 `<script>` 로 순서대로 로드합니다. ES 모듈은 `file://` 에서 CORS 때문에 막혀서 더블클릭 실행이 안 되기 때문입니다. 외부 CDN·웹폰트·라이브러리도 쓰지 않습니다.

## 매칭이 동작하는 방식

선택지마다 8개 학교 점수를 직접 매기면 18 × 4 × 8 = 576개의 숫자를 손으로 관리해야 하고 일관성 유지가 불가능합니다. 대신 **성향 축 벡터** 방식을 씁니다.

1. **7개 양극 축**을 정의합니다 (커리큘럼 자유↔구조, 대도시↔자연, 소수정예↔대규모 등).
2. **각 학교에 축별 프로필**을 부여합니다. 예를 들어 브라운은 `curriculum -2`(오픈 커리큘럼), 컬럼비아는 `+2`(코어 커리큘럼).
3. **각 선택지에 축 가중치**를 답니다. 보통 주축 1개 + 보조축 1개.
4. 답변을 축별로 합산해 **사용자 벡터**를 만들고, 학교 벡터와 **코사인 유사도**로 순위를 냅니다.

### 정규화에서 중요한 두 가지

**축별 표준편차로 나눕니다** (이론상 최대치가 아니라). 어떤 축은 주축으로 2번만 나오는데 보조 가중치로는 12번 실립니다. 최대치로 나누면 그런 축은 실제 합계가 늘 0 근처에 눌려서, 그 축에 정체성이 걸린 학교가 아무리 답해도 안 올라옵니다.

**축별 편향(평균)을 뺍니다.** 네 선택지의 가중치 합이 0이 아닌 축이 있습니다 (이 문항 세트에서는 `curriculum` 이 −1.0, `scale` 이 +1.0 쏠려 있었습니다). 보정하지 않으면 아무렇게나 찍어도 그 축이 한쪽으로 기웁니다. 이 보정 하나로 학교별 1위 점유율 편차가 7.2~16.7% 에서 10.8~14.2% 로 줄었습니다.

**학교 행렬은 축마다 8개교 평균을 뺍니다.** "아이비는 대체로 도시적" 같은 공통 성분을 없애야 축이 학교 간 상대 차이만 재게 됩니다.

**코사인을 씁니다** (내적이 아니라). 학교 벡터 크기로 나누지 않으면 축 값이 극단적인 학교가 방향과 무관하게 유리해집니다.

### 퍼센티지

1위는 **84~97%** 사이에 놓입니다. 답변이 뚜렷할수록, 그리고 1위 학교와 방향이 잘 맞을수록 높아집니다. 2·3위는 1위와의 코사인 격차만큼 떨어지고, `P₁ > P₂ > P₃` 와 최소 2포인트 간격이 항상 보장됩니다.

## 내용 수정하기

질문 문구를 고치는 것만으로는 아무것도 깨지지 않습니다. **가중치나 학교 벡터를 고쳤다면 반드시 검증 스크립트를 돌리세요.**

```bash
node scripts/check-reachability.js
```

검사 항목:

1. **도달성** — 무작위 답안지 4만 장에서 8개교가 모두 1위로 나오는가 (3% 미만이면 도달 불가, 30% 초과면 독식)
2. **현실적 사용자 시뮬레이션** — 일관되게 답하는 응답자 4만 명 기준 분포
3. **타당성** — 각 학교를 겨냥해 답하면 실제로 그 학교가 1위인가. **가장 중요한 항목입니다.** 하나라도 실패하면 그 학교를 대표하는 선택지가 부족하다는 뜻입니다.
4. **보정** — `cos_top` 과 뚜렷함의 실제 분포가 `js/scoring.js` 의 `CALIB` 구간과 맞는가
5. **엣지 케이스** — 전부 A / 전부 D / 번갈아 / 답이 완전히 상쇄된 경우

현재 상태 (모두 통과):

| 항목 | 결과 |
|---|---|
| 무작위 답안지 1위 점유율 | 10.8% ~ 14.2% (균등값 12.5%) |
| 현실적 사용자 시뮬레이션 | 8.3% ~ 15.0% |
| 겨냥 테스트 | **8/8 통과** |
| 1위 퍼센트 분포 | 최소 87 · 중앙 93 · 최대 97 |
| 단조성 `P₁>P₂>P₃` | 위반 0건 |
| 공유 링크 왕복 | 5만 회 무실패 |

**질문을 수정하면 `js/share.js` 의 `SHARE_VERSION` 을 올리세요.** 안 올리면 예전에 공유된 링크가 조용히 엉뚱한 결과를 보여줍니다. 버전이 다르면 앱이 "예전 버전 링크"라고 안내하고 다시 하도록 유도합니다.

## 공유 링크

답변 18개를 2비트씩 눌러 담아 5바이트로 만들고 base64url 로 인코딩합니다. 버전 태그와 체크섬을 붙여 최종 11자입니다.

```
#r=v1.GxsbGxAq
```

쿼리스트링이 아니라 **해시**를 쓰는 이유는 해시가 서버로 전송되지 않아 정적 호스팅의 리라이트 규칙에 영향을 받지 않고, `file://` 에서도 동작하기 때문입니다. 체크섬은 카카오톡·인스타에서 링크가 잘렸을 때 엉뚱한 결과 대신 안내 문구를 띄우기 위한 것입니다.

## 만든 것에 대해

학교별 성향 값은 각 학교의 널리 알려진 학제와 문화를 바탕으로 정했습니다 (브라운의 오픈 커리큘럼, 컬럼비아의 코어 커리큘럼과 맨해튼, 다트머스의 D-Plan과 시골 캠퍼스, 코넬의 7개 단과대, 유펜의 와튼, 프린스턴의 졸업논문, 예일의 레지덴셜 칼리지, 하버드의 규모). "좋다/나쁘다"가 아니라 "어느 쪽 성향이냐"만 나타냅니다.

각 학교와 아무 관련이 없는 비공식 팬 프로젝트입니다.
